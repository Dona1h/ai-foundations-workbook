04. 모델과 도구는 다릅니다

AI 모델은 답을 만드는 부분이고, 도구는 실제 일을 할 수 있게 해 주는 부분입니다.

사람에 비유하면

글을 잘 쓰는 친구가 있다고 생각해 보세요. 친구가 편지를 써 주는 것과 내 컴퓨터의 파일을 직접 고치는 것은 다릅니다. 파일을 고치려면 그 파일을 볼 방법과 바꿀 권한이 따로 필요합니다. AI도 비슷합니다. 단, AI가 사람처럼 이해하거나 책임을 진다는 뜻은 아닙니다.

05. 유창한 답이 정답은 아닙니다

생성형 AI는 배운 패턴과 지금 주어진 정보를 이용해 새로운 답을 만듭니다.

학습할 때

많은 자료의 패턴을 배우고, 이후 추가 학습으로 지시를 따르는 방식 등을 익힙니다. 학습한 모든 문서를 그대로 꺼내 보여 주는 검색창은 아닙니다.

대화할 때

현재 대화와 읽어 온 자료를 바탕으로 응답을 생성합니다. 대화에 정보를 넣는 것은 보통 모델 자체를 다시 훈련하는 것과 다릅니다.

구분뜻
그럴듯한 오류없는 사실·출처·기능을 사실처럼 말할 수 있습니다. 말투의 자신감은 정확도의 증거가 아닙니다.
지식의 시차모델이 최신 내용을 저절로 아는 것은 아닙니다. 검색이나 문서 읽기를 실제로 했는지 확인해야 합니다.
한 번에 보는 범위현재 참고할 수 있는 정보량에는 한계가 있습니다. 이전 대화가 모두 계속 보인다고 가정하지 않습니다.
추론·계산의 실수논리나 계산도 틀릴 수 있습니다. 중요한 계산은 계산기·코드·원자료와 대조합니다.
작은 실험

가상의 행사 정보를 두 문장으로 만든 뒤 AI에게 요약을 요청하세요. 일부러 장소를 비워 두세요. AI가 장소를 만들어 내는지, 빠진 정보라고 표시하는지 관찰하세요. 정답은 “모르면 묻거나 미정으로 남기는 것”입니다.

08. 파일과 폴더는 작업의 주소입니다

AI가 엉뚱한 파일을 고치지 않게 하려면, 먼저 내가 위치를 알아야 합니다.

공책과 서랍으로 생각하기

파일은 내용을 담은 공책, 폴더는 공책을 모아 놓은 서랍입니다. 경로는 그 공책이 어디에 있는지 알려 주는 주소입니다. 프로젝트는 한 작업에 필요한 파일을 모은 폴더라고 생각해도 좋습니다.

24. 오늘 할 일 목록: 먼저 범위를 정합니다

작고 단순해서, 무엇이 맞고 틀렸는지 직접 판단할 수 있는 연습입니다.

만들 결과

내 컴퓨터의 브라우저에서 여는 “오늘 할 일 목록”입니다. 한 줄을 입력하고 추가하면 목록에 보입니다. 빈 입력은 무시하고, 새로고침하면 목록이 사라집니다. 저장하지 않는 것은 이번 연습의 의도된 범위입니다.

구분뜻
할 것제목·입력칸·추가 버튼·목록 / 빈 입력 차단 / 키보드 Enter 추가
하지 않을 것로그인·데이터베이스·외부 API·설치 패키지·공개 배포·영구 저장
사용 파일index.html 한 개, 목표를 적을 README.md

AI에게 맡길 일짧은 계획, 예제 설명 또는 구현 초안, 수정 제안

학습 방법은 둘 중 하나

A. 다음 쪽 예제 파일을 직접 만들어 실행합니다.
B. 26쪽 요청으로 AI에게 같은 범위의 초안을 만들게 합니다.
둘을 한꺼번에 할 필요는 없습니다. 예제와 AI 결과가 똑같은 코드일 필요도 없습니다.

우리가 확인할 핵심

입력한 글자가 들어가는가, 빈 입력은 막히는가, 키보드로도 되는가, 새로고침 동작을 이해하는가입니다. 화려한 디자인과 자동화는 평가 항목이 아닙니다.

25. 직접 열 수 있는 최소 예제

아래 코드를 index.html로 저장한 뒤 브라우저에서 엽니다.

자체 작성 참고 코드 · 외부 라이브러리·네트워크 요청 없음
<!doctype html>

<style>
body{max-width:38rem;margin:2rem auto;padding:1rem;
  font:18px/1.7 system-ui,sans-serif;color:#222}
input,button{font:inherit;padding:.4rem}
li{overflow-wrap:anywhere}
</style>
<h1>오늘 할 일</h1>
<p>새로고침하면 목록이 사라지는 연습 문서입니다.</p>
<form id="form">
  <label for="task">할 일</label>
  <input id="task" maxlength="80" required>
  <button>추가</button>
</form>
<p id="message" role="status"></p>
<ul id="list"></ul>
<script>
const form = document.querySelector('#form');
const input = document.querySelector('#task');
const list = document.querySelector('#list');
const message = document.querySelector('#message');
form.addEventListener('submit', event => {
  event.preventDefault();
  const text = input.value.trim();
  if (!text) { message.textContent='할 일을 적어 주세요.'; return; }
  const item = document.createElement('li');
  item.textContent = text;
  list.append(item);
  input.value = '';
  message.textContent = '추가했습니다.';
  input.focus();
});
</script>
</html>

26. AI에게 맡겨도 범위는 내가 정합니다

계획을 보고 승인한 다음, 한 파일만 만들게 합니다.

먼저 보낼 요청

24쪽과 같은 조건으로 먼저 계획만 제안해 주세요.
- index.html 한 개, 외부 연결과 라이브러리 없음
- 할 일 입력, 버튼 또는 Enter로 추가
- 빈 문자열과 공백만 있는 입력은 추가하지 않음
- 입력한 글자는 HTML이 아니라 일반 글자로 표시
- 새로고침하면 목록은 사라짐, 이 점을 화면에 안내
- 입력칸에 label, 결과 안내에 접근 가능한 상태 표시

아직 파일 생성·수정은 하지 마세요.
  • 폴더와 변경 파일이 맞는지 확인했습니다.
  • 로그인·설치·외부 연결이 추가되지 않았습니다.
  • 빈 입력·Enter·새로고침 확인이 계획에 있습니다.

이 계획대로 index.html만 만들어 주세요.
